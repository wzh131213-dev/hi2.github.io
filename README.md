# 西游取经路（GitHub Pages 单页小游戏）

一个可直接部署在 **GitHub Pages** 的纯前端小游戏：玩家扮演孙悟空，在取经路上闯过 3 个关卡（花果山、白骨岭、火焰山）。

## 运行方式

- 本地直接双击打开 `/home/runner/work/hi2.github.io/hi2.github.io/index.html` 即可游玩。
- 或在仓库根目录启动任意静态服务器后访问（例如 VS Code Live Server）。

## 操作方式

- 键盘：方向键 / `WASD` 移动
- 移动端：页面底部方向按钮触摸控制
- 功能按钮：开始、暂停、重新开始

## 玩法说明

- 避开妖怪（👹）和陷阱（红色方块），被碰到会扣生命值。
- 收集经文（📜）和蟠桃（🍑）获取分数，蟠桃可回血。
- 抵达终点（🚩）进入下一关，完成 3 关即通关。

## 部署到 GitHub Pages

1. 推送代码到仓库默认分支。
2. 在 GitHub 仓库设置中打开 **Pages**。
3. Source 选择对应分支（通常是 `main`）和根目录（`/root`）。
4. 保存后等待部署完成，访问页面地址即可。

> 本项目不依赖后端与外部资源，离线也可运行。
